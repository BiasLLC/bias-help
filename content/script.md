# BIAS Script — Preview Guide

**Coming soon.** This guide describes the planned first public beta from the current product handoff. It is not a claim that Script has been released. [Join the beta notification list](https://bias.pub/script).

Version 1 is intended for iPad and supported Apple silicon Macs using Designed for iPad mode. **iPhone is on the roadmap, not part of version 1.** Pricing will be announced when confirmed.

## Start or import a script

Create a Film, Stage Play, or TV Multi-Cam script, or import a Fountain `.fountain` or Final Draft `.fdx` file. Imported files initially use Film format; change the profile afterward if needed.

Script uses readable Fountain text for the screenplay. Its working document package also stores app information such as notes. Export Fountain when you want a portable text copy.

## Write and format

Type Fountain conventions or use the element control to choose Scene Heading, Action, Character, Dialogue, Parenthetical, or Transition. The editor applies the layout for the selected format.

Character and scene-heading suggestions help maintain consistent names. Accept an autocomplete suggestion with Return. Stage Play is a formatting profile, not a production-management or cast-management system.

## Outline and scene notes

The scene sidebar follows your position in the script. Select a scene to jump to it, or expand the full-screen outline to see headings and notes together.

Select, add, rename, or reorder scenes in the outline. Structural changes are reflected in the screenplay. Edit scene notes in the outline on iPad and Mac. Scene notes are separate from printable screenplay text.

## Search and annotations

Use notes, tags, and boneyard passages to track questions, subjects, and possible cuts. The patent-pending search workflow brings those items and scene notes together. Narrow text searches to dialogue, action, characters, or scene headings when useful.

## Revisions and snapshots

Create named snapshots and establish a revision baseline to see changed lines. Review earlier work or restore it as a separate copy without overwriting the current draft.

Revision marks are shown in the editor. **They are not currently included in exported PDFs.** Keep original files and review exported output before sharing a production deliverable.

## Print and export

Export PDF, Fountain, or Final Draft FDX. Print the screenplay or outline separately. PDF options include a title page, page range, draft watermark, and custom header.

FDX is a compatibility conversion, not a lossless round trip. Advanced revisions, production metadata, custom styles, or unsupported elements may not survive unchanged. Keep the original FDX and compare the result after import or export.

## Files and offline work

Script stores document packages in iCloud when available, with local storage as a fallback. Downloaded scripts can be edited offline; changes synchronize when connectivity returns. Back up important scripts before testing a new version or resolving a conflict.

For sync problems, check your Apple Account, iCloud settings, network connection, and whether the document has downloaded on the other device. Do not remove a file merely because it is temporarily missing from one device.

## Other tools and limits

Focus Mode hides sidebars. Other implemented tools include scene numbering and locking, search and replace, writing statistics, approximate page count, spelling controls, title-page information, themes, zoom, and font choices.

Sprint timer, collaboration, exact paginated screenplay preview, and PDF revision marks are not current features. iPhone availability is planned for a later version.
