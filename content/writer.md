# BIAS Writer — User Guide

For Writer 2.0 public beta, including Writer Pro. Updated November 20, 2026. Beta features can change. Back up important writing before testing a new build.

## Start writing

Writer is a Markdown writing app for iPhone and iPad. Start in one workspace and organize your drafts, notes, and ideas with #tags. Writer Pro adds separate editable projects and Reference Documents.

Create a document and start typing. Writer saves automatically while you work and when you switch documents or leave the app. A document’s first line supplies its visible title.

If eligible older library data is found, Writer offers **Import Previous Library**. Follow that workflow rather than moving or deleting old files yourself. Keep a separate backup until you have checked the imported library.

## Documents and organization

Use the document list and its menus to create, arrange, duplicate, archive, or delete documents. A duplicate is an independent copy.

Add tags such as `#research`, `#chapter1`, or `#semester2` in your writing. Use the tag filter to find related documents within your workspace. Clear filters if a document seems to be missing.

Writer allows editing in one designated workspace. Other existing projects remain readable and can still be previewed, printed, backed up, and exported. Writer Pro makes all projects editable, enables additional projects, and adds Reference Documents.

## Markdown and annotations

Markdown stores formatting as readable plain text:

- `# Heading` or `## Subheading` for headings (include a space after the hash).
- `**bold**` and `*italic*` for emphasis.
- `- List item` for a bulleted list.
- `[Link text](https://example.com)` for a link.
- `> Quotation` for a blockquote.

Writer adds three writing tools:

- **Memo:** `((Check this date.))` keeps an editorial note beside the relevant text.
- **Omit:** `[[A passage I might cut.]]` preserves an alternative passage while letting you leave it out of clean output.
- **Tag:** `#first_draft` helps organize and find related writing.

Memos and omits do not count toward document or project word counts. Preview and export controls determine whether annotations appear in your output; do not assume an annotation is hidden without checking those controls.

## Find your work

Find can search the current document or project. Results are grouped by document with surrounding text. Selecting a result opens a read-only preview; explicitly open it when you want to edit.

Use **Memos**, **Omits**, and **Tags** to gather those items and narrow the results. Documents that have not downloaded from iCloud are reported as not yet searched, rather than treated as empty.

## Merge and split

Merge brings selected documents together in the order you choose. Review the new document name and the archive options before confirming. The merge dialog explains what will happen to the originals.

Split lets you divide a longer document at the cursor or by headings. Review the preview and destination before confirming. Back up important work before a major restructuring.

## Preview, print, and export

Preview is the output workspace. Choose **This Document** or **All Documents**, then set annotation, layout, and Reference Document options. Print or export the preview as PDF, Markdown, HTML, or plain text.

**Quick Export** creates a clean Markdown, HTML, or plain-text copy of the current document using fixed defaults. Use Preview when you need control over what is included.

**Back Up Projects** makes a ZIP of untouched Markdown files in their project folders, including archived documents. Store a backup separately from your working library.

## Import and backups

Import individual `.md` or `.markdown` files through Files, Open With, or Share. They go into the open project; if none exists, Writer creates an Imported project.

Writer does not currently import whole project folders or restore a backup ZIP as a complete project. Keep the ZIP as a file backup; do not treat it as an in-app one-click restore mechanism.

## Archive and permanent deletion

Archive removes a document from the active list without deleting its file. Archived documents can be previewed read-only and restored.

**Deleting an active or archived document permanently removes its file after confirmation. Writer has no in-app Trash or Undo for permanent deletion.** Export or back up anything you may need before deleting. Do not rely on a 30-day recovery window.

## Files, iCloud, and offline use

Documents are ordinary Markdown files at `iCloud Drive/BIAS Writer/Markdown Library/<Project>/`. They are not proprietary document packages.

Downloaded documents remain available offline. Edits synchronize when iCloud becomes available. A file that has not downloaded needs a connection before Writer can open or search it. Writer provides an explicit review screen for conflicting iCloud versions.

If something is missing, check the current project, tag filters, Archive, iCloud Drive settings, and whether the file has downloaded. Use the same Apple Account on your devices. Keep backups before moving library folders or resolving conflicts; do not delete a competing folder without checking its contents.

## Devices and controls

On iPhone, navigate between the project list, documents, and editor. iPad uses a wider split layout when space permits. Hardware keyboard controls include formatting and Find; consult the app’s menus for the commands available in your current view.

The Mac implementation uses Designed for iPad mode on supported Apple silicon Macs. Availability depends on the distributed build and Apple’s listing; the current beta invitation identifies eligible devices.
